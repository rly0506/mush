### 排版：三级阶梯 + 等宽数据分离

- 对话正文 **15px/1.7**（主区放大，读起来是「对话」不是「日志」）；头犬回复 600 字重区分角色；
- 卡片标题 13px/600；元信息 12px；
- 所有数据（dispatch id/哈希/时间/金额/session）统一 Consolas + 独立字号 + 偏青——
