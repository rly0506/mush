## 🎯 里程碑详细规划

### Milestone 1 (M1)：影子评测与实战战绩 ELO 天梯榜引擎（GOAL-052）
- **业务目标**：以量化、客观的战绩数据消除对各模型纸面参数的盲信，构建真实实战 ELO 天梯榜。
- **核心交付规格**：
  1. **自动影子分流评测器**：在后台针对任务样本自动分流多犬盲测；
  2. **多维 ELO 天梯计算模型**：从「代码正确率」、「单 Token 产出能效」、「耗时延迟」与「防御漏洞率」综合计算 ELO 积分；
  3. **在册犬天梯榜大屏**：看板直观展示各犬动态段位（Master/Diamond/Gold）与历史对决战绩。

---

### Milestone 2 (M2)：战绩反馈闭环与自适应路由权重自进化（GOAL-053）
- **业务目标**：让调度系统具备“自我学习、越用越聪明”的动态自适应能力。
- **核心交付规格**：
  1. **实战结果闭环回填（Feedback Loop）**：每次派发和辩论的人类采纳/拒绝、测试通过/失败结果自动打标回填；
  2. **路由权重自进化引擎**：根据最近 N 次实战战绩动态调整 GOAL-039 智能路由器的各领域推荐权重；
  3. **成本能效帕累托前沿算法**：在预算限制下自动求解最高胜率的犬只派发组合。

---

### Milestone 3 (M3)：极简系统托盘常驻伴侣与全局热键雪橇浮窗（GOAL-054）
- **业务目标**：消除浏览器切屏开销，让雪橇队随时随地通过全局快捷键呼之即来。
- **核心交付规格**：
  1. **系统托盘守护进程（Tray Companion）**：纯轻量化托盘常驻，资源占用 < 20MB；
  2. **全局热键（Alt+Space）唤起 Floating Sled 浮窗**：在任意屏幕位置瞬间弹出输入框，秒级下发指令；
  3. **划词与剪贴板极速审查**：选中代码即可一键拉起雪橇队执行审查、辩论或重构。

---

### Milestone 4 (M4)：多犬协作全景战报与研发能效大屏（GOAL-055）
- **业务目标**：为人类管理者提供清晰量化的多 Agent 团队研发效能全景透视。
- **核心交付规格**：
  1. **研发能效矩阵（Engineering Velocity Matrix）**：统计各阶段耗时、打回率、代码审查收益与 Token 投资回报率（ROI）；
  2. **周期性全景战报自动生成**：每周/每日自动汇总生成高质量 Markdown 研发复盘报告；
  3. **看板效能大屏图表**：纯 SVG 呈现团队吞吐率走势与协作拓扑演进图。
