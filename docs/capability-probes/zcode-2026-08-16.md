## 额外发现

- `app-server`：stdio 协议服务器——比 CLI stdout 解析更稳的深度集成通道
  （类似黄金参照经 pi 的 RPC 路子），M3 可作为进阶选项；
- `--resume <sessionId>` / `-c`：会话可续命，断点续跑友好；
- 登录态为 Z.AI OAuth（`zcode login`）而非本地 API key——**预算计量方式 UNKNOWN**：
  per-actor 成本可测性待 M3 探测（D20 预算记账相关）。
