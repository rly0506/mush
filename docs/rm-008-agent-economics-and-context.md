## 🎯 里程碑详细规划

### Milestone 1 (M1)：派发回执零开销真实用量对账与 Prompt Cache 细分计量（GOAL-056）
- **业务目标**：以本地确定性代码消除大模型经济学“黑盒失真”，让每一笔支出和 Prompt Cache 节省额清晰透明。
- **核心交付规格**：
  1. **零开销本地用量提取器**：在子进程退出时，由 Node.js 派发器确定性提取 `input_tokens`, `output_tokens`, `cache_creation_tokens`, `cache_read_tokens`，记录入 `T1Receipt`，0 额外 Token 消耗；
  2. **模型单价矩阵（Pricing Matrix）**：解耦各 Provider（Claude 3.5 Sonnet, DeepSeek V3/R1, Codex 等）的标准单价与缓存命中折扣；
  3. **后验台账对账与可视化**：在派发完成后将实际费用回填至 `ledger.jsonl`，在看板预算与效能大屏直观展示“实际支出”与“缓存节约总额”。

---

### Milestone 2 (M2)：上下文基线透明化、@-mention 门禁与结构化不变式压缩（GOAL-057）
- **业务目标**：落实严格的上下文卫生纪律，最大化保护 Prompt Cache 寿命并防止注意力污染。
- **核心交付规格**：
  1. **`@file` 快速装载与安全门禁**：输入框支持 `@path/to/file` 语法；$\le 300$ 行直接内联（省 1 次工具往返），$> 300$ 行自动拦截并转为大纲索引（防大文件多轮重复计费）；
  2. **Pass-Quiet / Fail-Rich 输出管道**：自动化测试通过时仅返回单行摘要，失败时提取关键断言与倒数 50 行堆栈，防止几千行噪音塞满上下文；
  3. **实时上下文用量胶囊（Context Gauge）**：对话工坊顶部展示规则/工具/历史 Token 分布与占比；
  4. **结构化不变式压缩（Compact）**：提供一键压缩按钮，按严格 Schema 提炼决策、已改文件哈希与待办，以超低开销实现会话冷启动复用。
