## 三、 薄弱点深度标注与改进措施

### ⚠️ 薄弱点 1：`src/web/page.ts` 单文件代码臃肿（3332 行）
- **现象**：前端所有的 HTML 结构、CSS 样式、SVG 图标、以及客户端 JavaScript 逻辑全部内嵌在 `page.ts` 的模板字符串中；
- **隐患**：随着 GOAL-035~042 增加 Diff 审查、Trace 瀑布、记忆图谱等组件，单文件复杂度激增，维护与代码审阅成本上升；
- **改进措施（Ponytail 瘦身）**：将 `page.ts` 按关注点拆分为：`src/web/ui/styles.ts`（CSS 主题）、`src/web/ui/icons.ts`（SVG 资产）、`src/web/ui/client-scripts.ts`（前端交互逻辑）以及 `src/web/ui/views/`（各模块组件）。

### ⚠️ 薄弱点 2：多 Agent 深度协作机制尚未产品化（可选协作功能）
- **现象**：GOAL-028/042 定义了拓扑和消息总线，但用户在聊天和使用时，还不能像“点一个按钮”那样直观触发辩论或流水线；
- **改进措施**：落地 RM-005 的三大想法——**聊天底栏一键按需触发、页面排版自适应刷新、独立全功能工作台**。
