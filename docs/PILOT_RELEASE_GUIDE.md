# mush 商业化试运行发版指南 (Pilot Release Guide)

**版本**: `v0.1.0-pilot`  
**代号**: 原厂战衣联邦 (Native Harness Federation)  

---

## 一、 为什么选择 mush？

不同厂商的模型在自己的**原生 Harness（原厂战衣）**中才能发挥 100% 战力：
- **Claude 3.7 Sonnet / Claude 3.5 Sonnet 跑在 Claude Code 里**：独享原厂自适应/扩展思考（Hybrid Reasoning）、全局 Agentic 代码重构与多文件精准重构；
- **DeepSeek-R1 / DeepSeek-V3 跑在 dsh 里**：原生流式 Thinking 思考链透出、万 Token 厘级极致性价比与极速工程落地；
- **Gemini 2.5 Pro / 2.5 Flash 跑在 agy 里**：超大 200万+ 全图谱上下文吞吐、原生多模态视觉审计与深度推理；
- **OpenAI o3-mini / o1 / GPT-4.5 跑在 Codex 里**：高阶数学推理、复杂状态机验证与严谨算法演变；
- **Kimi k1.5 / moonshot-v1 跑在 kimi-code 里**：长程代码库精准检索与长文档技术对账；
- **GLM-4-Plus / Grok-2**：跨拓扑灵活接入，支持辩论竞技场与红蓝攻防对抗。

mush 不把大模型抹平成均码的裸 API，而是作为**本地总线编排原厂战衣**，提供统一白板、流水线协同、红蓝对抗与权威安全预算闸门。

## 二、 用户如何安装 mush？

我们提供三种极简分发形态，适配不同开发者习惯：

### 🌟 形态 1：绿色免安装桌面包（最推荐，0 配置解压即用）
1. 从官网或 GitHub Releases 下载 `mush-v0.1.0-pilot-windows-x64.zip`；
2. 解压到任意本地目录（如 `D:\mush` 或 `C:\Tools\mush`）；
3. 双击 `mush-start.cmd`（或桌面快捷方式），自动在默认浏览器中拉起协同看板：`http://127.0.0.1:4790/`。

### ⚡ 形态 2：Node.js / npm 极速命令行安装（面向 CLI 重度用户）
如果您的电脑已安装 Node.js（`>= 24.0.0`）：
```bash
npm install -g mush-ai
# 在任意项目目录一键启动
mush
# 或直接打开看板
mush board --open
```

### 📦 形态 3：单文件安装器 / 系统托盘伴侣
运行 `mush-Setup-0.1.0.exe` 安装包：
- 自动创建桌面快捷方式与开始菜单；
- 启动后托盘常驻，支持全局热键 `Alt+Space` 随时呼出悬浮雪橇浮窗（划词审查、即时指令交互）。

## 三、 原厂 CLI 是自动安装的吗？

**答：不是自动静默安装，而是采用「智能自动感知 + 诊断引导（Doctor）+ 可选一键脚本」模式。**

- **为什么不强制静默全家桶安装？**
  1. **环境纯净与零权限风险**：静默安装全局 npm/python 包极易导致权限报错（EACCES）或污染开发者的全局开发环境；
  2. **真正的 BYOK（自带战衣）**：用户通常只需使用自己常用的 1~2 个厂商（如只用 Claude 和 DeepSeek，无需安装 Gemini），按需配置保证轻量。

- **mush 的智能感知机制**：
  1. **自动探测**：启动时自动扫描环境变量与原厂配置目录（`~/.claude/`、`~/.dsh/`、`~/.cc-switch/` 等）；
  2. **就绪点亮**：已安装的 CLI 会在看板中自动点亮为「★ 当前激活 / 就绪」；
  3. **名册医生**：未安装的犬只会在看板上温和标注「未检测到 CLI」，并附带一键复制的官方安装命令；
  4. **（可选）一键环境初始化助手**：运行 `scripts/setup-harnesses.cmd` 可根据需要一键批量安装缺失的原厂 CLI。

## 四、 安全与隐私承诺

- **纯本地运行**：100% 本地 SQLite / JSONL 存储，零外部遥测与数据收集；
- **零信任 Caller-Token 鉴权**：本地随机高熵 Token 鉴权，防御跨站 CSRF 与未授权访问；
- **工作区沙箱**：严格白名单访问控制，禁止越权读取工作区外敏感系统文件；
- **服务端权威预算**：微美元级预算锁定与 Telemetry 真实对账，杜绝 API 账单过度开销。
