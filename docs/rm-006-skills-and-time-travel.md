## 🎯 里程碑详细规划

### Milestone 1 (M1)：跨 Harness 技能双向转译与统一热挂载引擎（GOAL-048）
- **业务目标**：让全局存储的 Skills（如 Claude Code Skills、Codex Markdown Skills、Antigravity Skills、dsh Skills）一次编写，全队在册犬（DeepSeek/Claude/Kimi/ZCode/AGY）通用执行。
- **核心交付规格**：
  1. **跨格式 AST 转译器**：统一解析 YAML frontmatter、参数规范与 prompt 模板，自动转译为目标 Harness 可识别的格式；
  2. **统一热挂载与按需注入**：支持看板实时加载本地 `~/.gemini/config/skills`、`~/.claude/skills` 等外部技能库；
  3. **技能安全沙箱**：对技能中的脚本/命令执行进行路径穿越拦截与凭据泄露扫描。

---

### Milestone 2 (M2)：会话与代码时空状态树与因果时间旅行快照（GOAL-049）
- **业务目标**：消除 Agent 编码过程中的“试错不可逆”恐惧，提供极速时光倒流与分支对比能力。
- **核心交付规格**：
  1. **因果状态图（Causality State Tree）**：每次派发和状态变更记录微快照，构建可追溯的 Git-like 因果分支图；
  2. **时间旅行回溯器（Time-Travel Reverter）**：支持在看板一键回滚会话与工作区至任意历史节点（undo/redo）；
  3. **状态分支对比视窗**：直观对比两个不同历史分支的代码差异与执行效果。

---

### Milestone 3 (M3)：跨犬共享黑板协作空间与读写白名单仲裁（GOAL-050）
- **业务目标**：彻底免除头犬频繁中转（Relay Tax），实现工作犬围绕安全黑板的去中心化异步协作。
- **核心交付规格**：
  1. **黑板数据模型（Blackboard Space）**：分区存储全局工件（Artifacts）、待解难题（Open Issues）与假设（Hypotheses）；
  2. **读写白名单仲裁器**：为各犬分配严格的黑板区块读写权限，防止并发冲突；
  3. **事件驱动条件唤醒（Blackboard Triggers）**：当指定黑板区域发生状态变更时，自动唤醒下游订阅犬。

---

### Milestone 4 (M4)：液态临时战时攻关小队与指挥犬选举协议（GOAL-051）
- **业务目标**：应对突发大型紧急 Bug 或高难度 Goal，实现自适应小队动态组建与解散。
- **核心交付规格**：
  1. **战时指挥犬动态选举**：根据任务特征与各犬能力画像自动选举最适合本次攻坚的临时组长；
  2. **液态攻关小队（Holonic Task Force）**：动态绑定 2~3 只工作犬组成临时协同集群，共享独立子黑板；
  3. **任务结束自动解散与成果归档**：任务交付并经审核后，小队自动解散，上下文沉淀为符号记忆。
