# GOAL-024 任务自动完成探测与可视化路径导图（Task Auto-Completion & Visual DAG Mindmap）

## 目标与背景

用户提出两项核心交互与自动化诉求：
1. **任务自动完成探测**：自动识别已经完成的任务，并将其自动放入完成池（`DONE`），避免人工机械点选，同时对执行失败/超时任务自动置为受阻（`BLOCKED`）；
2. **可视化路径导图 / 思维导图**：根据现有任务流向与 Goal 归属，在看板中绘制原生思维导图/DAG 路径图示，已完成（绿）、进行中（脉冲蓝）、待办（灰）、受阻（红）必须具备鲜明色彩区分，并支持点击下钻三透镜全景抽屉。

---

## 架构设计

### 1. 后端：任务生命周期与派发回执自动联动 (`src/web/dispatch.ts` & `src/web/tasks.ts`)

- **派发启动联动**：当关联了 `task_id` 的派发被受理（`ADMITTED` / `RUNNING`）时，若任务处于 `IDEA` / `READY` / `QUEUED`，自动跃迁至 `IN_FLIGHT`；
- **派发成功联动**：当派发执行结束且 `status === 'PASS'`（`exitCode === 0` 且无超时）：
  - 自动将关联任务迁移至 `DONE`；
  - 自动追加一条 `translateTaskTransition` 活动记录（「任务「X」自动转入完成」）；
  - 经 SSE 实时广播更新；
- **派发失败/超时联动**：若派发结果为 `FAIL` 或 `TIMEOUT`：
  - 自动将关联任务迁移至 `BLOCKED`；
  - 自动追加一条「任务「X」因执行失败转入受阻」活动记录。

### 2. 前端：原生 SVG/CSS 路径导图 / 思维导图引擎 (`src/web/page.ts`)

- **零外部资源铁律**：纯原生 SVG + CSS + 语义 HTML 构建，不引入任何外部图表库（D3/Mermaid/Echarts 等 CDN 外链一律禁止）；
- **视图双模切换**：在任务池控制栏提供「📋 泳道看板」与「🗺️ 路径导图」一键无缝切换；
- **状态色彩与视觉体系**：
  - 🟢 **已完成 (DONE)**：翠绿（`#10b981` / `var(--ok)`），带实线圆环、勾选图标与耗时；
  - 🔵 **进行中 (IN_FLIGHT / QUEUED)**：呼吸蓝（`#3b82f6` / `var(--info)`），带动态脉冲光晕（CSS Pulse）与执行犬 Logo；
  - ⚪ **待办中 (IDEA / READY)**：石板灰（`#64748b` / `var(--ink-dim)`），带虚线框与待命标识；
  - 🔴 **受阻中 (BLOCKED)**：预警橙红（`#ef4444` / `var(--ember)`），带警示图标；
- **路径与拓扑连线**：
  - 左侧为 Goal 枢纽中心节点，向右延伸各个任务节点（DAG 流向）；
  - 采用平滑 SVG 贝塞尔曲线连接各个节点，线条色彩跟随前序状态；
- **三透镜直通**：
  - 点击导图上任意任务节点，直接唤起 GOAL-023 全景抽屉（时间线、Trace 日志、犬只直连、台账下钻）。

---

## 验收规格（Acceptance Criteria）

1. **自动完成流转**：派发关联任务且执行为 PASS 时，`GET /api/tasks` 中该任务 `status` 自动变为 `DONE`；
2. **自动受阻流转**：派发关联任务且执行为 FAIL 时，该任务 `status` 自动变为 `BLOCKED`；
3. **导图渲染与切换**：点击「🗺️ 路径导图」成功切换至图示视图，SVG 正确绘制节点与贝塞尔曲线；
4. **四态色彩严格区分**：DOM/CSS 中正确应用 `node-done`（绿）、`node-inflight`（蓝）、`node-ready`（灰）、`node-blocked`（红）；
5. **交互直通**：点击导图节点触发 `openTaskDrawer` 弹出三透镜抽屉；
6. **零回归**：全量测试套件（396+ 项）100% 绿灯。
